# ugos-bridge

Read-only telemetry for UGOS / UGREEN NAS hosts, Docker containers, and libvirt
virtual machines, with Prometheus, MQTT discovery, and Home Assistant cards.

## Components

- [Bridge](bridge/README.md) — Go service, container setup, configuration, and telemetry reference.
- [Home Assistant cards](ha-cards/README.md) — detailed and compact Lovelace dashboards, installation, and builds.
